# 40 минут — дневник зала

Статическое русскоязычное PWA без сборки, зависимостей и сервера данных. Записи остаются только в `localStorage` текущего браузера.

Новый черновик предзаполняет каждый подход значениями последнего фактически выполненного такого же подхода. Если истории ещё нет, повторы и секунды берутся из нижней границы плана, а вес остаётся пустым. Предзаполнение не отмечает подход выполненным. Нажатие «Готово» запускает или перезапускает таймер с длительностью отдыха конкретного упражнения; «Пропуск» и снятие отметки таймер не запускают.

В меню две области: «Регулярные тренировки» с дневником, историей и программой, и «Специализированные тренировки». Раздел «Кисти» — инструкция на русском по [комплексу AAOS при синдроме запястного канала](https://www.orthoinfo.org/globalassets/pdfs/a00789_therapeutic-exercise-program-for-carpal-tunnel_final.pdf): две растяжки, скольжение срединного нерва и две серии скольжения сухожилий. Содержит дозировки, инструкции и иллюстрации из источника © American Academy of Orthopaedic Surgeons, не заменяет назначение специалиста. Можно записывать отдельные занятия с датой и временем, в том числе несколько в день; силовой журнал не меняется. Текст и рисунки доступны офлайн; оригинал PDF — по внешней ссылке, с интернетом.

«Стопа и голеностоп» — второй специализированный комплекс по [программе AAOS](https://www.orthoinfo.org/globalassets/pdfs/foot-and-ankle-conditioning-program---2025.pdf): 10 упражнений с дозировками и иллюстрациями из источника © American Academy of Orthopaedic Surgeons. Занятия фиксируются отдельно от кистей и силового журнала; текст и рисунки доступны офлайн. Комплекс не заменяет назначение специалиста.

## Запуск локально

Не открывайте `index.html` через `file://`: service worker и установка PWA так не работают.

Из каталога приложения запустите:

```bash
npm run dev
```

Откройте <http://localhost:8080/>. Для запуска нужны Node.js и Python 3, пакеты устанавливать не требуется. Остановить сервер можно через Ctrl+C. `localhost` считается безопасным контекстом и подходит для локальной проверки service worker.

Важно: публикуйте или раздавайте **только каталог `gym-app`**, не корень Obsidian-хранилища. В приложении нет копии исходной заметки и нет доступа к другим файлам vault.

## Установка на Android

1. Разместите содержимое этого каталога на статическом HTTPS-хостинге. Корнем сайта должен быть `gym-app` либо отдельный подкаталог с неизменной структурой файлов.
2. Откройте адрес в Android Chrome хотя бы один раз с интернетом.
3. Нажмите «Установить» в приложении или выберите «Установить приложение» в меню Chrome.
4. После первой успешной загрузки оболочка и текст программы доступны офлайн. Внешние иллюстрации Strength Level не входят в кэш и без сети могут не отображаться.

При следующем открытии после публикации новой версии service worker обновляет кэш приложения и удаляет предыдущую оболочку. Локальная история и черновики при этом сохраняются.

Ограничения:

- фоновые таймеры в мобильном браузере могут приостанавливаться; приложение восстанавливает остаток по сохранённому времени окончания, но не обещает системный фоновый сигнал;
- вибрация зависит от разрешений и состояния вкладки;
- данные не синхронизируются и пропадут при очистке данных сайта/Chrome или удалении хранилища приложения;
- Markdown-экспорт — человекочитаемая резервная копия для заметок, но автоматический импорт/восстановление из неё не реализован.

Регулярно экспортируйте историю в Markdown.

## Тесты

Требуется современный Node.js. Пакеты устанавливать не нужно.

```bash
npm test
```

Тесты покрывают создание и сохранение состояния, предзаполнение из истории и плана, переходы статусов с автозапуском таймера, deadline-логику таймера и Markdown-экспорт.
